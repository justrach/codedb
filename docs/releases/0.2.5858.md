# CodeDB 0.2.5858

Hosted semantic retrieval moves to Gemini `gemini-embedding-001`.

## Gemini hosted embeddings

0.2.5857 and earlier requested `jinaai/jina-embeddings-v2-base-code` from the hosted embeddings endpoint. The default is now `gemini-embedding-001` at the same 512D contract, with its own query encoding and vector-space identity so Gemini vectors are never mixed with older ones.

A local ANN sidecar built with the former hosted Jina or Qwen default is rebuilt once in the background the first time a hybrid query sees it; the bounded exact rerank serves that request meanwhile. Custom endpoints and explicit model overrides are left alone. To keep Jina, set `CODEDB_EMBEDDINGS_MODEL=jinaai/jina-embeddings-v2-base-code`.

Local BM25/symbol retrieval, the watcher, and the installer are unchanged.
