# CodeDB 0.2.5857

The installer now registers codedb in the MCP clients it can already detect, instead of leaving ten of them for a hand edit.

## More MCP clients

0.2.5856 and earlier auto-registered Claude Code, Codex, Gemini CLI, Cursor, Windsurf, and Devin. Agents on oh-my-pi, Hermes, Qwen Code, ZCode, Trae, Cline, Copilot CLI, Antigravity, Kiro, and OpenCode still had to paste a config snippet.

The installer writes each client's documented file and schema when that client's config directory or CLI is already present. Malformed JSON is left untouched rather than replaced. `codedb nuke` removes the same entries.

Antigravity does not share Gemini CLI's settings file. Registration and Deepwiki go only to `~/.gemini/antigravity/mcp_config.json`. The stray `~/.gemini/config/mcp_config.json` path stays in nuke so an older install still deregisters. Nuke also removes the non-CN Trae `User/mcp.json` path the installer can create.

Retrieval, the watcher, and hosted embeddings are unchanged.
