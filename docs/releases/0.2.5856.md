# CodeDB 0.2.5856

Skip Git worktree forests so they cannot exhaust the macOS directory watch budget.

## Watcher skip (#754)

On macOS, directory watches consume the default 1024 vnode cap before file watches. A parent checkout that contains a `.worktrees/` folder of linked Git worktrees could fill that cap, overflow source files into periodic hashing, and multiply the cost across MCP clients ([#751](https://github.com/justrach/codedb/issues/751)).

`.worktrees` is now a default skip directory, like `.git` and `node_modules`. `codedb list_dir` collapses it unless it is the listing root. Relative paths are matched after the scan root is stripped, so a server whose root **is** a worktree checkout still indexes that checkout's source.

This does not raise `max_watched`, share watchers across MCP processes, or close the leftover #751 periodic-overflow work.
